# AI Engineer Path

A curated, phase-by-phase learning platform for going from full-stack developer to **applied AI engineer**. It's built on the [roadmap.sh AI Engineer roadmap](https://roadmap.sh/ai-engineer).

- 9 phases: Python → LLM fundamentals → Prompting & APIs → Embeddings → RAG → Agents → Multimodal → Production → Advanced
- 70+ hand-picked, link-verified resources, split into **Start here**, **Go deeper** and **Bookmark**
- A topic tracker (Not started → Learning → Implementing → Completed) and a project checklist for each phase
- A weekly-pace selector that rescales every time estimate
- Progress stored in `localStorage`, with JSON export/import

## Stack
Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · Motion · Lucide

## Develop
```bash
npm install
npm run dev
```

Curriculum content lives in `src/lib/curriculum.ts`. Edit that file to add or swap resources.
